# 2026-03-28

## 1. 概述

过去 7 天（约 2026-03-21 至 2026-03-28）最值得关注的 3 个点：第一，Codex 相关能力进入密集迭代期，`openai/codex` 在 3 月 26 日发布 `0.117.0`（插件与多代理路径工作流升级），3 月 27 日连续发布 `0.118.0-alpha` 预发布，且 ChatGPT 端同步上线 “Plugins in Codex”。第二，OpenAI 在治理与安全侧连续发布公开材料，包括 Model Spec 设计方法、面向 AI 滥用风险的 Safety Bug Bounty、以及面向青少年场景的策略模板，开发者可直接复用到审核流程。第三，ChatGPT 产品面快速更新（购物、文件库、移动端侧栏、位置共享、企业分析看板），但状态页也显示本周 API 与 ChatGPT 多次短时故障，虽均已恢复，生产环境仍建议加强降级与重试策略。

## 2. 官方发布与公告

- **Inside our approach to the Model Spec**
  - 发布时间：2026-03-25（来源页日期；未标注具体时区）
  - 来源：https://openai.com/index/our-approach-to-the-model-spec/
  - 要点：
    - OpenAI 公开解释 Model Spec 的设计逻辑，把“模型该如何行为”做成可读、可讨论、可迭代的公共框架。
    - 文中强调 Chain of Command（OpenAI/开发者/用户指令优先级）用于冲突处理，兼顾可控性与安全边界。
    - 官方明确 Model Spec 既是当前行为描述，也是持续优化目标，不是“一次性定稿文档”。

- **Introducing the OpenAI Safety Bug Bounty program**
  - 发布时间：2026-03-25（来源页日期；未标注具体时区）
  - 来源：https://openai.com/index/safety-bug-bounty/
  - 要点：
    - 新增面向“滥用与安全风险”的公开赏金计划，补充传统安全漏洞赏金。
    - 重点覆盖 agent 风险（含 MCP 场景）、数据外泄与平台完整性等 AI 原生风险类别。
    - 官方表示与安全研究社区协作，按影响与可复现性进行分流与处置。

- **Update on the OpenAI Foundation**
  - 发布时间：2026-03-24（来源页日期；未标注具体时区）
  - 来源：https://openai.com/index/update-on-the-openai-foundation/
  - 要点：
    - Foundation 表示未来一年预计投入至少 10 亿美元，覆盖生命科学、就业与经济影响、AI 韧性、社区项目。
    - 文中提到此前已宣布的 250 亿美元长期承诺（聚焦治病与 AI 韧性）正在推进早期投资。
    - 对普通开发者的间接影响在于：政策与安全研究投入会更快转化为可执行规范与生态要求。

  - 要点：

## 4. Codex 产品与工程效率动态

- **ChatGPT Release Notes：Plugins in Codex**
  - 发布时间：2026-03-26（来源页日期；未标注具体时区）
  - 来源：https://help.openai.com/en/articles/6825453-chatgpt-release-notes
  - 要点：
    - Codex 新增插件目录，可发现、安装并复用由 apps/skills 组成的工作流包。
    - 插件支持把技能、可选集成和 MCP 配置打包，降低团队统一开发流程成本。
    - 对使用 Codex 的团队，意味着“从个人脚本到团队模板”的迁移门槛下降。

- **Using Codex with your ChatGPT plan（文档更新）**
  - 发布时间：Updated: yesterday（约 2026-03-27，精确时间/时区未标注）
  - 来源：https://help.openai.com/en/articles/11369540-codex-in-chatgpt
  - 要点：
    - 文档确认 Codex 覆盖 CLI、IDE 扩展、Web、App（含 Windows/macOS）以及云端委托执行。
    - 明确插件与企业控制策略（Workspace app controls、RBAC、Compliance API 可见性）。
    - 对企业管理员的直接影响是：可在统一权限模型下治理 Codex 与插件能力。

- **openai/codex 发布节奏加快（0.117.0 与 0.118.0-alpha）**
  - 发布时间：0.117.0 于 2026-03-26 22:27；0.118.0-alpha.3 于 2026-03-27 23:09（来源页显示时间；时区未明确）
  - 来源：https://github.com/openai/codex/releases
  - 要点：
    - 0.117.0 把插件工作流提升为一等能力（启动同步、`/plugins` 浏览、安装/移除流程改进）。
    - 新增多代理路径化地址（如 `/root/agent_a`）与结构化代理间通信，利于并行任务编排。
    - 预发布版本在 3 月 27 日持续迭代，说明 Codex 工具链仍处于快速演进周期。

## 5. 产品功能与开发者生态

- **Powering Product Discovery in ChatGPT**
  - 发布时间：2026-03-24（来源页日期；未标注具体时区）
  - 来源：https://openai.com/index/powering-product-discovery-in-chatgpt/
  - 要点：

    - 通过 ACP（Agentic Commerce Protocol）扩展商品发现，强调更全、更快、更准的商品信息。
    - 官方称本周向 Free/Go/Plus/Pro 推出，对“搜索-比较-决策”型用例影响明显。

- **ChatGPT Release Notes（3/23~3/26）多项可用性更新**
  - 发布时间：2026-03-23 至 2026-03-26（来源页日期；未标注具体时区）
  - 来源：https://help.openai.com/en/articles/6825453-chatgpt-release-notes
  - 要点：
    - 3/23：File Library 上线，上传文件可沉淀复用，跨会话引用更顺滑。
    - 3/25：超长粘贴自动转附件；Google Docs/Sheets/Slides 连接器统一到 Google Drive app。
    - 3/26：移动端侧栏简化，新增可选位置共享（含家长控制开关）。

- **Workspace analytics for ChatGPT Enterprise and Edu（文档更新）**
  - 发布时间：Updated: yesterday（约 2026-03-27，精确时间/时区未标注）
  - 来源：https://help.openai.com/en/articles/10875114-workspace-analytics-for-chatgpt-enterprise-and-edu
  - 要点：
    - 企业/教育版分析支持 analytics viewer 角色、任务洞察、项目/技能趋势与 CSV 导出。
    - 明确该看板是聚合分析，不含原始消息与文件内容；合规场景需走 Compliance API。
    - 数据刷新非实时（通常 6-12 小时，SLA 48 小时），运营看板需避免按秒级解读。

- **Helping developers build safer AI experiences for teens**

  - 来源：https://openai.com/index/teen-safety-policies-gpt-oss-safeguard/
