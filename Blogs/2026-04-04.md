# 2026-04-04

## 1. 概述

过去 7 天（约 2026-03-28 至 2026-04-04）OpenAI 侧最值得关注的 3 个点：第一，Codex 商业化与团队落地明显加速，4 月 2 日官方推出面向 Business/Enterprise 的 Codex 按量计费席位，同日 Enterprise 发布新 Codex seat 与费率卡更新，意味着团队可以用更低固定成本先跑试点，再按 token 规模化。第二，公司层面连续两条高影响公告（3 月 31 日融资、4 月 2 日收购 TBPN），显示 OpenAI 在算力、资本与传播渠道上继续强化。第三，产品与稳定性层面本周有 ChatGPT CarPlay 新入口，但状态页仍记录登录、SSO 与 API 短时故障，生产环境仍应保留重试与降级策略。

## 4. Codex 产品与工程效率动态

- **Codex now offers pay-as-you-go pricing for teams**
  - 发布时间：2026-04-02（来源页日期；未标注具体时区）
  - 来源：https://openai.com/index/codex-flexible-pricing-for-teams/
  - 要点：
    - Business/Enterprise 可新增“Codex-only seats”，无固定席位费，按 token 用量计费。
    - ChatGPT Business 年付价格从 $25 下调到 $20（每席位），降低团队整体试点门槛。
    - 官方同时强调 Plugins 与 Automations 协同，定位为“从试点到规模化”的工作流入口。

- **ChatGPT Enterprise & Edu - Release Notes：New Codex seats in ChatGPT Enterprise**
  - 发布时间：2026-04-02（条目日期；未标注具体时区）
  - 来源：https://help.openai.com/en/articles/10128477-chatgpt-enterprise-edu-release-notes
  - 要点：
    - Enterprise 新增 Codex seat（仅 Codex 访问，不含 ChatGPT workspace 全量访问）。
    - 新 Enterprise 工作区开始采用 token-based rates；既有 Enterprise/Edu 等仍在 legacy message-based rates，待迁移。
    - 对管理员影响最直接：需要同步调整 seat 类型、SCIM 供应与预算监控策略。

- **Codex changelog：Codex CLI 0.118.0**
  - 发布时间：2026-03-31（来源页日期；未标注具体时区）
  - 来源：https://developers.openai.com/codex/changelog
  - 要点：
    - 新增 `codex exec` prompt+stdin 组合输入、动态 bearer token 刷新等能力。
    - Windows/Linux 沙箱与本地 `.codex` 保护逻辑修复，降低权限与稳定性风险。
    - 对日常工程流的意义是：跨环境执行一致性与自动化脚本可靠性提升。

- **Releases · openai/codex（窗口内版本节奏）**
  - 发布时间：2026-03-31 至 2026-04-02（来源页显示时间；时区未标注）
  - 来源：https://github.com/openai/codex/releases
  - 要点：
    - `0.118.0` 稳定版于 2026-03-31 发布。
    - 随后在 2026-04-01 至 2026-04-02 连续发布 `0.119.0-alpha.2/3/4/5` 预发布版本。
    - 说明 Codex 工具链仍处于高频迭代周期，团队应区分 stable 与 pre-release 的采用策略。
